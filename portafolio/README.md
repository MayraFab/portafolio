# Portafolio en React (Guía Práctica #4 - SENATI)

## Cómo abrirlo
1. Descomprime la carpeta `portafolio` (por ejemplo en C:/xampp/htdocs).
2. Abre una terminal dentro de la carpeta y ejecuta:
   npm install
   npm run dev
3. Abre http://localhost:5173/ en el navegador.

## Personalizar
- Cambia tu foto: reemplaza `src/assets/miFoto.png` por una foto cuadrada tuya con el mismo nombre.
- Cambia "Giancarlos Barboza" por tu nombre en `Navbar.jsx` y `Banner.jsx`.
- Edita tus datos en `Perfil.jsx`, `Habilidades.jsx`, `Proyectos.jsx` y `Contacto.jsx`.
